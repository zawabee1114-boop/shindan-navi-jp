## 3. 構築方針（4軸で同時進行）

### A. デザイン刷新（外注受領 → 私が実装）
- 全96ページをゼロから青春アニメ調で刷新（外注ブリーフ準拠）
- 192体キャラ（人96+動物Big5の32+血液型サブタイプ24）を統一画風で
- **実装は解約ナビと同じ手法**: 外注デザイン受領 → Playwrightスクショ検証ループ → 合格でデプロイ
- 共通レイアウト/コンポーネントを先に固め、各診断は世界観差し替えで効率化

### B. 集客（PDCA金脈の磨き込み・記事追加は最小限）
**最優先（実データで筋が見えている）**
1. **DiSC診断 強化** — 1ページ目独占射程・タイトル最適化・コンテンツ厚み・内部リンク
2. **血液型相性 強化** — 急上昇の勢いを乗せる
3. **血液型サブタイプ診断 新導線** — 自己理解→相性の順序を強める
4. **MBTI相性／友達相性 回復** — 急落-20〜30位の3ページにテコ入れ

**記事追加は控えめ**
- 診断ナビは「単発記事」より「診断＋シーン軸」の体験勝負
- 必要なら DiSC派生（業務応用・チーム活用）／MBTI相性 深掘りのみ

### C. 収益化（Phase 1の取りこぼし回収）
- AdSense Slot ID 配信（既にca-pub設定済 → ID投入のみ）
- **PASS ¥390 / PRO ¥590** Stripe本人確認後の有効化
- 統合プロファイル＋AIプロンプトカードがPASS購入の動機
- 月替わり限定診断＋タイムカプセル＋時間軸グラフ＝PRO継続課金

### D. バイラル（無料・無制限・変更不可）
- **招待相性（friend-compat・blood-compat/friend）は完全無料**
- 4プライバシーモード（こっそり/招待/片方向/完全共有）
- 結果シェアOGP画像の精度＝シェア率に直結
