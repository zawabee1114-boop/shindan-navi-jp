# 診断ナビ 最強サイト構築方針（2026-06-08）

> 競合を観察→空白を特定→そこに全リソースを集中投下→「同種サイトでこれより強いものは無い」状態を作る。

---

## 1. 結論（先に方針）

診断ナビは次の4点で**全ての競合を上回る**サイトにする。

1. **唯一の「8診断統合エンジン」**: 単発診断サイトは無数にあるが、複数診断を横断翻訳する仕組みは世界的に空白。これを核に「あなたを一人の人物として可視化する」体験を独占する
2. **学術根拠＋日本独自モデルの中立性**: 占い系・心理テスト個人サイトのE-E-A-T空白を埋める。出典・確認日・disclaimerを全ページに可視化
3. **完全無料の招待相性によるバイラル装置**: 競合は招待相性を「無し／回数制限／有料」で運用。診断ナビは無制限無料・4プライバシーモードで圧倒
4. **時間軸プロダクト**: 競合は「1回受けて終わり」。診断ナビは時間軸グラフ・月替わり限定・タイムカプセル・コレクションで**使い捨てない診断**を作る

「単発診断で誰かに勝つ」のではなく、**勝てる戦場を新しく作って独占する**。

## 3. 競合を上回る4本柱（具体的に何を作るか）

### 柱A: 統合プロファイルを「サイトの顔」にする
- 8診断統合は競合不能の本丸。`/profile/` を主役にして全結果ページから常時誘導
- 達成率バー（1/8 → 8/8）を全結果ページ上部に常設＝**コンプリート欲を視覚化**
- 達成時のご褒美＝**Big5動物16体**（完全擬人化動物・各診断の人キャラと別系統で特別感）
- AIプロンプトカード（ChatGPT/Claude/Geminiに自分の人格を渡す）を統合の出口に
- レーダー・棒グラフ・相性マトリクスで「数字で見える自己理解」

### 柱B: 学術根拠＋誠実さで信頼の堀を作る
- 全診断ページに**学術ソース3件以上を可視化**（古川1927／能見1971／Sakamoto2004／Big5研究等）
- 「ブラハラ警告」「科学的相関は限定的」「占い・運勢ではない」を結果末尾に常設
- 監修者ページ拡充（実在のみ・架空NG）。長期は大学・研究室監修コラム
- これにより**占い系は構造的に追随できない**。心理テスト個人サイトも出典を持たない＝差別化不可

### 柱C: 招待相性で勝手に伸びる装置を持つ
- 友達相性／血液型相性／MBTI相性／恋愛相性を**完全無料・無制限**
- **4プライバシーモード**（こっそり／招待／片方向／完全共有）で「相手にバレない」配慮
- パーソナライズOGP（「あなたと相性◯◯%」を画像生成）でTwitter／LINE／Instagram拡散
- 招待された相手が診断ナビに着地→自分も受診→さらに招待…の自己増殖ループ
- 競合の招待は有料・回数制限が大半。診断ナビは**永久無料で開放**して新規流入を止めない

### 柱D: 時間軸プロダクトで「使い捨てない診断」にする
- 競合は1回受けて終わり。診断ナビはPRO ¥590/月で**継続体験**を売る
- **時間軸グラフ**（全期間の性格変化・過去の自分との比較）＝他サイトに存在しない
- **月替わり限定診断**（毎月新しい・PRO訴求のFOMO）
- **タイムカプセル**（未来の自分への手紙・1年後に開封通知）
- **獲得バッジ・コレクション**（ゲーミフィケーション）
- PASS ¥390買い切りはAIプロンプトカード1回付き＝**ライトな入口**

## 5. やらないこと（捨てる戦略）

- **占い・スピリチュアル参入**（ブランド毀損・若年層離れ）
- **YMYL越境**（メンタル疾患・発達障害・医療判定）
- **雑多な単発診断の量産**（統合エンジンに乗らない＝うちの強みを殺す）
- **派生URL量産**（詳細はハイブリッド方式＝同一URL内展開・GoogleHCU対策）
- **架空監修者**（E-E-A-T違反・法的リスク）
- **創作命名**（学術系・中立命名のみ）
- **既存URLの変更**（SEO資産を壊さない・必要時は301）
