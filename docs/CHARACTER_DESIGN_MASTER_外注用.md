# 診断ナビ キャラクター設計マスター（外注用ドラフト）

全96タイプ x 男女2版の画像生成前に使うキャラクター設定台帳。
目的は、診断ごと・タイプごと・男女版ごとのキャラクター被りを防ぎ、顔立ち・髪型・髪色・体格・表情・ポーズ・服装・小物・構図まで先に設計すること。

## 共通ルール

### 画像サイズ・余白の基準

- サイト実装で扱いやすいよう、全キャラの納品サイズは `1024x1024 PNG` を標準にする。
- 生成時点から1:1正方形構図を指定し、後処理でも正方形へ統一する。
- キャラ本体は中央配置、外接サイズは80〜90%。頭・耳・角・尻尾・翼・足先を切らない。
- 縦長/横長で出た画像は、切り抜きではなく白〜薄パステル背景の余白追加で正方形化する。
### 年齢感・等身の基準

- 目標は「幼めの大学生」。子供・中学生・マスコットではない。
- 1枚目テストのような6〜6.5頭身の若いアニメキャラを基準にする。2枚目テストのような5頭身前後の幼すぎる顔・体型は避ける。
- 少女漫画/乙女ゲーム風に寄る場合は、顎を少し丸く、服をカジュアル寄りに、背景を白く軽くして診断ナビUIへ戻す。

- 絵柄: 診断ナビ参考画像に合わせた、明るい現代日本アニメ調。幼めの大学生だが子供化しない。標準は6〜6.5頭身。
- 塗り: きれいなセル塗り、細い線、丸い頬、大きい瞳、白く抜けたUI向け背景。少女漫画・乙女ゲーム風の過剰な艶、長い首、細い顎、低年齢マスコット化は禁止。
- コスプレ強度: 日常服ではなく、タイプが一目で伝わる「役割衣装」。ただし版権風・ガチファンタジー・暗い雰囲気は禁止。
- 男女差分: 同じタイプでも、顔立ち・髪型・髪色・表情・衣装シルエット・ポーズ・小物の持ち方を変える。
- 横断差分: 同じ小物を連発しない。眼鏡、ノート、マイク、カフェ、花、工具、カメラは使用診断とタイプを限定する。
- 背景: タイプ記号は補助。キャラ本体のシルエットと表情を主役にする。
- 禁止: 読める文字、実在ロゴ、医療・病名っぽい表現、占い・オカルト感、武器、暗いホラー演出。

## 横断レビュー基準・被り防止レーン

- 計画/戦略系: INTJ、ENTJ、山羊座、Pragmaで使う。ただしINTJは盤面/設計図、ENTJは指揮棒、山羊座は登るシルエット、Pragmaは条件カードに分ける。
- 記録/チェック系: ISTJ、DiSC C、thorough、A-typicalで使う。ただしISTJは手帳、DiSC Cはルーペ/定規、thoroughは監査ファイル、A-typicalは書類トレーに分ける。
- 癒し/支援系: ISFJ、DiSC S、蟹座、O-gentle、Agape、恋愛依存 安定型が近い。ISFJはケアポーチ、DiSC Sは休憩ラウンジ、蟹座は蟹爪/甲羅、O-gentleはティーマグ、Agapeは傘、安定型は植物で分ける。
- 芸術/創作系: ISFP、Multi視空間、B-focused、AB-typical、魚座で使う。ISFPはパレット、視空間は立体ブロック、B-focusedは小型作品、AB-typicalは二色カード、魚座は水彩/魚ヒレに分ける。
- 旅/冒険系: ESTP、射手座、O-explorer、B-typicalが近い。ESTPはスポーツギア、射手座は矢羽根/的カード、O-explorerは地図/双眼鏡、B-typicalは趣味カメラに分ける。
- 社交/盛り上げ系: ENFP、ESFP、DiSC i、O-typical、友達ムードメーカーが近い。ENFPは旗、ESFPはステージ、DiSC iはメガホン、O-typicalは迎えるホスト、友達ムードメーカーはクラッカーで分ける。
- メガネはINTP、DiSC C、金銭vigilance、AB-analystなど理性系に限定し、同じ丸眼鏡を連発しない。
- カップ/マグはO-gentleに寄せる。牡牛座は焼き菓子/布、蟹座は蟹爪/甲羅、友達聴き上手はイヤーカフ/相談クッション、Storgeはアルバム/栞へ変更する。
